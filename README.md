# Udemy Clone (HTML & CSS)

This project is a **basic Udemy-inspired website clone** created using **HTML and CSS**. It was built as a beginner front-end project to practice webpage structure and styling.

## Pages Included

* **Home Page** – Displays the main layout similar to Udemy with navigation and course sections.
* **Contact Page** – A simple page where users can find contact information or send messages.

## Technologies Used

* **HTML5** – Used to build the structure of the website
* **CSS3** – Used for styling and layout design

## Purpose of the Project

The goal of this project is to practice:

* HTML page structure
* CSS styling
* Creating multi-page websites
* Building UI layouts similar to real-world websites

## How to Run

1. Clone or download this repository
2. Open `index.html` in your web browser

## Project Status

This is a **beginner-level front-end project** and currently focuses only on the design. No backend functionality is implemented.
